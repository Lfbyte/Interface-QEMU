## Como usar?

## Dependências
- QEMU

- O projeto usa a biblioteca: tk/tkinter. Verifique se o pacote Tk está instalado em sua distribuição:

> pip install -r requirements.txt

ou

> **Ubuntu/Derivados**:
> * sudo apt-get install python-tk ou sudo apt-get install python-tk
> 
> **Arch Linux**:
> * pacman -Sy tk ou sudo pacman -Sy tk

- Produzido com python 3.13
